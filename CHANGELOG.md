# Changelog

All notable changes to this project are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] — 2026-08-19

### Added

- Self-hosted simulator for live calls, SMS, email, Instagram DMs, and LinkedIn DMs
- Trainer tools for prospects, hidden facts, methodologies, scorecards, and drills
- Representative practice ring with patience, engagement, concession, and unlock engines
- Citation-gated debriefs that must quote methodology and transcript
- Artifact review for real call transcripts and written threads
- Docker Compose deployment with an embedded SQLite database
- Mock provider mode for local development without API keys
